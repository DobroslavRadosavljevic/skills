# Banned words

Decorative use fails. A real tapestry, an underscore character, or a landscape photo can stay. Inflections count (`delves`, `showcasing`, `meticulously`). If a new fog word acts like these, cut it too.

Replace: delete the word. If the sentence still stands, keep it. If not, put a noun or a number in the hole.

`Unlock robust, seamless proxy infrastructure` → `Sticky residential IPs, 60-minute sessions, $500/month pool.`
