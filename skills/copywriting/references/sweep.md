# Sweep

Run this before you send. A failed box means rewrite that span.

## Process

- [ ] No CMS talk, research leftover, or agent instructions
- [ ] Outline differs from sibling pages (H2s, opener, closer, FAQ)
- [ ] Product name where a person would say it, not stuffed
- [ ] Claims have a source, or they are gone; no fake hurry

## Promise

- [ ] Reader, job, and how much they already know match the lead
- [ ] One promise in the H1 and first 40 words
- [ ] Title, H1, deck, and main button agree
- [ ] Every leftover feature has a “so you can…”, or it was cut
- [ ] Button is action plus result (or this page is not asking yet)

## Slop

- [ ] No decorative token from [slop-words.md](slop-words.md). One is a fail.
- [ ] No “It’s not X. It’s Y.” / “not just X but Y” / “whether you’re” / “we’ve got you covered”
- [ ] Lists are not all triples; no filler adjective pairs
- [ ] No Moreover / Furthermore / Additionally as openers
- [ ] No “In conclusion” that repeats the lede
- [ ] No “and that matters” / “the part everyone misses”
- [ ] Em dashes not stacked in a short paragraph
- [ ] Sentence length varies
- [ ] No “Certainly!” / “I hope this helps”
- [ ] Everyday words. No jargon pile. No stacked nouns
- [ ] Instructions ≤20 words. Descriptions ≤25 words. One idea per sentence
- [ ] One word per idea (no login/sign-in/auth shuffle)
- [ ] Docs/UI/errors: ASD-STE100 (active, short, defined terms)

## Four checks

- [ ] Clear in five seconds: what, who for
- [ ] No spare words
- [ ] A specific reason to care
- [ ] Proof, or an honest limit

## Surface (one)

- [ ] **UI:** next-state commands; errors say what + fix; empty state has status + action
- [ ] **Site:** five-second test; one main button; outline not cloned
- [ ] **Docs:** one kind per page; condition before the step; no `easy` / `just`; STE sentence limits
- [ ] **Email/push:** one status or one offer; specific subject
- [ ] **Legal/billing:** exact, calm, no fake hurry

## Batch

- [ ] Openings do not match
- [ ] H2 sets are not one recipe shuffled
- [ ] YAML fields are not a name swap
- [ ] Repeated UI strings (`Save`, `Delete`, errors) use the same words
